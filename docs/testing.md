## Ручная проверка release на эмуляторе

1. Установлен v1 (release, versionCode 1). «Начать без расчёта» → «+250 мл». В дневнике поиск `yumurta`, «Яйцо куриное, варёное», «Штуки» показывает вес порции 50 г; 2 шт. дают 155 ккал.
2. Профиль → «Выбрать папку» → системный выбор `Documents/HealthChecker` → «Разрешить». Сразу создан проверенный `HealthChecker-….json`. Профиль показывает «Папка подключена», время копии и не показывает несохранённых изменений.
3. Ещё два добавления воды. На каждое изменение создаётся новая копия; в папке остаются ровно две последние.
4. `adb install -r` v2 поверх v1: 155 ккал, 13 г белка и 750 мл воды сохранились.
5. Удаление приложения, установка v2 заново, «У меня уже есть резервная копия», выбор новейшего файла. Диалог показал «4 записи (последняя — 19 октября 2026) и 0 своих продуктов». После подтверждения обзор снова показал 155 ккал / 13 г / 750 мл и подсказку заново выбрать папку.
6. `adb install -r` v3 поверх восстановленной v2: данные сохранились. Холодный запуск занял 2,3 с; у v2 он занимал 15 с, потому что старт ждал разбора каталога.
7. Тёмная тема с масштабом шрифта 1,3: обзор и дневник читаются, текст переносится без обрезки, цвета без фиолетовых значений Material по умолчанию.
8. `aapt2 dump permissions`: в APK нет `INTERNET` и других пользовательских разрешений, только служебное `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`.

## Не проверено

- Реальный телефон и Android 8.0–15. Проверен только эмулятор Android 16.
- Включённый авиарежим не включался. Офлайн-работа следует из отсутствия сетевого разрешения и встроенного каталога.
- Отзыв доступа к папке, заполненный накопитель и закрытие приложения во время записи проверены только unit-тестами `BackupService`/`BackupCoordinator` с поддельным хранилищем.
- Отмена системного выбора папки или файла на устройстве не нажималась: код просто игнорирует пустой результат.
- Ориентация, системная кнопка «Назад» в формах и сохранение черновика при повороте вручную не проверялись.
- Производительность на слабых телефонах: из-за загрузки хоста время запуска на эмуляторе нерепрезентативно. R8 и baseline profile не включены.
- Open Food Facts в каталоге нет: при подготовке сервис отвечал HTTP 503.
