# HealthChecker 1.16.7

Обновление можно поставить прямо из приложения: **Профиль → О приложении → Обновления**. Или скачайте **[HealthChecker-update-v1.16.7.apk](https://github.com/saint-1406/HealthChecker/releases/download/v1.16.7/HealthChecker-update-v1.16.7.apk)** и установите поверх текущей версии; `.sha256` служит для проверки файла.

## Калории видеотренировок

В списке видеотренировок вместо значка «play» теперь стоит примерная оценка, сколько ккал сжигает всё занятие (например, «≈ 85 ккал»). Это та же оценка, что попадает в дневник при записи видео: MET каждого упражнения × вес × время работы по разметке, паузы не считаются. Берётся вес из профиля; если он не указан — оценка для 70 кг, о чём сказано над списком. У своих видео без разметки остаётся значок.

Версия **1.16.7**, внутренний Android **versionCode 23**. Подпись, каталог продуктов, база штрихкодов и карта прежние.
