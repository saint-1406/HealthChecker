# HealthChecker v15 — сканер товаров

Скачайте **HealthChecker-update-v15.apk** в Assets ниже. Это **полный установщик**: подходит для первой установки и обновления. Устанавливайте поверх имеющегося приложения, без удаления — дневник сохранится. Базовый APK и промежуточные версии не нужны.

## Что нового

- Сканирование штрихкодов упаковок камерой, чтение фотографии штрихкода и ручной ввод цифр.
- Поиск сохранённого товара на телефоне без интернета. Штрихкоды EAN/UPC/GTIN проверяются по контрольной цифре; варианты с ведущими нулями находят одну карточку.
- По кнопке «Найти онлайн» — поиск в Open Food Facts. В сервис отправляется только штрихкод, без фотографий, профиля и дневника.
- Проверка и исправление названия, бренда, калорий и БЖУ перед сохранением. Если товара нет, его можно добавить по этикетке. Сохранённая карточка открывает обычную форму порции и работает с корзиной приёма пищи и ингредиентами блюд.
- Учёт основы «100 г / 100 мл». Для перевода значений на 100 мл в граммы требуется указать измеренный вес 100 мл; плотность воды не подставляется автоматически. Несовместимые единицы упаковки не смешиваются с единицами питания.
- Штрихкоды входят в резервную копию формата 8; старые форматы 1–7 поддерживаются. История питания сохраняет свои значения.
- Исправлены запрос разрешения камеры для «Фото на потом» и обработка запоздавших результатов фотографий. Отказ в доступе к камере оставляет галерею и ручной ввод доступными.

Открыть сканер: **«Записать еду» → значок штрихкода справа от поиска**. Это чтение штрихкода; таблица пищевой ценности с фотографии автоматически не распознаётся. Данные найденного товара нужно сверить с упаковкой. Покрытие ассортимента магазинов Азербайджана не гарантируется.
