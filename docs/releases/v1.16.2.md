# HealthChecker 1.16.2

Для установки или обновления скачайте только **[HealthChecker-update-v1.16.2.apk](https://github.com/saint-1406/HealthChecker/releases/download/v1.16.2/HealthChecker-update-v1.16.2.apk)** (около 191 МБ) и откройте поверх текущего приложения. Не удаляйте установленную версию перед обновлением. Файл `.sha256` нужен только для проверки контрольной суммы, устанавливать его не требуется.

- Новая вкладка «Находки»: личный каталог еды, товаров ухода и других интересных покупок. Фото из камеры или галереи, штрихкод, бренд, заметки, избранное и поиск.
- Для находки можно сохранить несколько мест покупки с ценой и отдельной заметкой. Находки не изменяют дневник питания.
- Встроенная офлайн-карта Азербайджана: магазины и интересные места, отметки долгим нажатием, по GPS или вручную. Интернет приложению не нужен.
- Прогулки по кнопке «Начать прогулку»: GPS-запись с уведомлением, пауза, продолжение и завершение. История маршрутов и подсветка записанных посещений помогают выбирать другие места для прогулок. Автоматической прокладки маршрутов в этом выпуске нет.
- Резервные копии ZIP сохраняют находки, фотографии, места и маршруты вместе с прежними данными. Старые JSON-копии по-прежнему восстанавливаются. Восстановление заменяет все данные, включая находки и прогулки.
- Новый формат номера версии: **1.16.2**, внутренний Android versionCode **18**. Обновление ставится поверх ранее опубликованной версии **16.1**, дневник сохраняется.

Установщик — полный APK, подходит и для первой установки, и для обновления. Карта и база штрихкодов находятся внутри; отдельно скачивать их на телефон не требуется.

Для записи прогулки нужна точная геолокация. Разрешение уведомлений позволяет управлять записью из шторки. После остановки процесса запись автоматически не возобновляется; сохранённую прогулку можно продолжить вручную. Точность GPS и поведение при выключенном экране зависят от телефона и условий приёма спутников.

Карта: © OpenStreetMap contributors · ODbL 1.0; Mapsforge 0.25.0; AndroidSVG 1.4. Источники и лицензии включены в приложение и репозиторий.

Проверки: 183 JVM-теста, 12 Android-сценариев на эмуляторе, GPS при выключенном экране и с паузой, восстановление фото/места/маршрута после удаления приложения, подписанное обновление 16.1 → 1.16.2 с сохранением дневника. Lint без ошибок. [Подробности проверок](https://github.com/saint-1406/HealthChecker/blob/main/docs/testing-v1.16.2.md).
