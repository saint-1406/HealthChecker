# HealthChecker 16.1 — база товаров без интернета

В приложение встроена полная доступная пищевая выгрузка Open Food Facts от 29 октября 2026 года. Поиск по штрихкоду работает на телефоне с первой установки и не требует подключения к сервисам.

- **4 682 262 карточки** с корректными штрихкодами; калорийность известна у **943 729**. Остальные карточки помогают определить товар и заполнить значения по этикетке. Данные сообщества нужно сверять с упаковкой.
- Сначала проверяются личные карточки, затем встроенная база. Миллионы товаров доступны через сканирование или ввод цифр кода; обычный поиск по названиям сохраняет каталог из 7 834 продуктов.
- Если товар отсутствует или найденная карточка не подходит, можно добавить собственную: название, фото упаковки, калории, БЖУ и вес/объём. Личные карточки и фото входят в резервную копию.
- У приложения **нет разрешения INTERNET**. Ссылки YouTube открываются внешним приложением; свои видео и таймер разметки работают локально.
- Данные сохранённых дневников и личных карточек сохраняются при установке обновления поверх прежней версии.

При первом поиске база подготавливается в приватных данных телефона: SQLite занимает 391 446 528 байт. Полная сжатая база — 154 003 442 байта — уже включена в APK, загрузки после установки нет. База не гарантирует наличие каждого товара магазинов Баку. В исходной выгрузке 1 290 корректных записей помечены Azerbaijan; глобальные карточки также покрывают импортируемые товары.

**Установка:** скачайте `HealthChecker-update-v16.1.apk` и откройте на Android 8.0 или новее. Это полный установщик: подходит для новой установки и обновления. Отдельный файл `HealthChecker-products-v16.1.sqlite.gz` нужен для самостоятельного использования данных; приложение уже содержит эту базу.

Данные Open Food Facts: ODbL 1.0, отдельные данные DbCL 1.0. В релизе доступны полный производный каталог, контрольные суммы, отчёт и лицензии. Исходная ревизия: `d07e994d22778c80da576ed5f7f9cb5f1b6d8c6e`. Отчёт учитывает все 4 882 161 исходную запись: 199 852 строки с некорректными GTIN пропущены, 47 дублей кодов объединены.

Версия Android: versionName `16.1`, versionCode `17`, applicationId `az.healthchecker.app`, прежний ключ подписи.
