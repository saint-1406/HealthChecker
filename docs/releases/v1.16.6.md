# HealthChecker 1.16.6

Скачайте только **[HealthChecker-update-v1.16.6.apk](https://github.com/saint-1406/HealthChecker/releases/download/v1.16.6/HealthChecker-update-v1.16.6.apk)** и установите поверх текущей версии. Удалять приложение перед обновлением не нужно. `.sha256` служит для проверки файла. Начиная с этой версии следующие обновления можно ставить прямо из приложения.

## Обновление из приложения

**Профиль → О приложении → Обновления**: проверка последнего выпуска на GitHub, «Что нового», загрузка с прогрессом и отменой, проверка файла (SHA-256, размер, пакет, номер версии, ключ подписи) и передача системному установщику. Раз в день при запуске приложение тихо проверяет новую версию и показывает строку «Доступна версия X» (можно выключить). Для этого появилось разрешение INTERNET: сеть используется только для GitHub по HTTPS, данные дневника никуда не отправляются. Каталог, сканер, карта, дневник и видео по-прежнему работают без сети.

## Профиль проще

Вместо длинного списка — сводка (параметры тела, цели на сегодня) и разделы, которые открываются отдельными экранами: тело и активность, цели питания, инвентарь, резервная копия, главный экран и вода, оформление и язык, о приложении. **Инвентарь** теперь кнопка с числом блюд, а не список внутри профиля. Все прежние настройки на месте.

## Настройка программы по анкете

Семь шагов: пол, возраст, рост, вес (и желаемый вес), ограничения по здоровью (колени, поясница, плечо, запястья, шея, грыжа, давление, беременность/после родов), оборудование дома (гантели, гиря, штанга, турник, брусья, скамья, резинки, коврик, скакалка), цель (набрать массу, просто набрать вес, нарастить мышцы, сбросить жир, поддерживать, подтянуть тело, выносливость), активность и опыт, сколько дней в неделю и минут на занятие. Приложение считает калории (Mifflin–St Jeor с поправкой на цель и безопасным минимумом), белки, жиры, углеводы и воду, подбирает неделю тренировок из упражнений приложения с учётом оборудования и ограничений и даёт рекомендации. Ничего не меняется, пока вы не нажмёте «Применить план»; ответы можно изменить позже, они входят в резервную копию. Это общие рекомендации, не медицинский совет.
