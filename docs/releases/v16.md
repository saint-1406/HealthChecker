# HealthChecker v16

- Сканер автоматически ищет товар: сначала в личной базе, затем в Open Food Facts.
- Отдельные состояния для отсутствующего товара и недоступного сервиса, повторный поиск онлайн.
- «Добавить вручную» позволяет создать карточку по этикетке; для неподходящего результата есть «Не тот товар?».
- Необязательное фото упаковки камерой или из галереи. Фото остаётся на телефоне, входит в резервную копию и показывается при выборе порции.
- Сохранённый товар узнаётся по штрихкоду без интернета.

Фото не распознаёт пищевую ценность автоматически: название и данные этикетки проверяет пользователь. Общедоступный онлайн-источник пока Open Food Facts; GS1 Azerbaijan не подключён.

Формат резервной копии — 9, чтение прежних копий сохранено. Существующий лимит копии 25 МБ сохраняется; фотографии уменьшаются до 960 px и 180 КиБ каждая.

Полный подписанный установщик: `HealthChecker-update-v16.apk`, подходит для новой установки и обновления поверх прежней версии с сохранением данных.
