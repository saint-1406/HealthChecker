# Проверки 1.16.4 (versionCode 20)

01.11.2026. Исходный коммит: `09c7942333780b025694499c99794fe4beac2001`.

## Регрессии и совместимость

На прежнем поиске позиции воспроизведены 6 отказов из 13 тестов: пропущенный системный fused-источник, первый GPS-фикс позже 20 секунд, задержанный свежий фикс, ожидание при уже доступной приблизительной позиции и некорректная обработка времени сохранённого измерения. Журнал: `.local/release-1.16.4/red.log`.

После исправления прошли 13 тестов на Android 15. Затем матрица расширена до **38 проверок на API 26, 31 и 35 (Android 8, 12 и 15)**. Проверены точная/приблизительная геолокация, свежесть кеша, реальные времена измерения, поздний первый фикс, отключённые источники, отказ в разрешении, таймаут и отмена с удалением подписок.

Независимое ревью дополнительно выявило зависание `busy`, если отмена произошла до старта IO-корутины. `LocationViewModelTest` воспроизвёл отказ на прежней реализации (`cancellation-red.log`). Обработчик завершения теперь устанавливается синхронно до запуска ленивой задачи; очистка выполняется и тогда, когда тело задачи не было запущено. Повторное ревью существенных замечаний не обнаружило.

Финальный полный прогон: **231 JVM-тест, 0 падений, ошибок и пропусков; lint — 0 ошибок**. Журнал: `.local/release-1.16.4/checks-final.log`. Последующее изменение Android-теста затронуло только режим сравнения текста (`substring=true`); тестовый APK пересобран (`native-package.log`). Код приложения после полного прогона не менялся.

## Android 16, настоящий сервис геолокации

На тестовом эмуляторе `HealthCheckerTest` (API 36, авиарежим) прошли **6 инструментальных тестов**:

- Первый GPS-фикс через 25 секунд не отменяется прежним 20-секундным таймаутом.
- Системный fused-источник возвращает приблизительную позицию без спутникового фикса.
- Поиск с карты отменяется и запускается повторно; после получения позиции видна её точность.
- Сохраняются непродовольственная находка, фото, магазин и избранное.
- Встроенная карта и история прогулок работают офлайн; карта не перекрывает кнопки.
- Запись прогулки остаётся foreground-сервисом, пауза не добавляет время.

Результат: **OK (6 tests)**, 119.523 секунды. Журнал: `.local/release-1.16.4/native.log`. Геопозиции задаются через тестовые провайдеры настоящего Android LocationManager, а не через Robolectric. При старте эмулятор также выдавал ANR системной оболочки `com.android.systemui`; это ограничивает оценку скриншотов. ANR HealthChecker в проверках не обнаружен. Настоящие GNSS-приёмники и особенности прошивок пользовательских телефонов этими тестами не проверяются.
