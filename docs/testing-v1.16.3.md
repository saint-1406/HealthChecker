# Проверки 1.16.3 (versionCode 19)

31.10.2026. Проверка выпуска на Windows с локальным Android SDK и прежним ключом подписи. Исходный коммит подготовки: `2c51362e8151f6073432abceab29159631dd9d7c`.

Сначала воспроизведены три блокера выпуска:

- Компиляция: после добавления `precise` позиционный аргумент кнопки начала прогулки перестал соответствовать сигнатуре. Обработчик теперь передаётся по имени `onDenied`.

- Android lint `MissingPermission`: чтение сохранённой геопозиции теперь явно обрабатывает `SecurityException` и исчезновение провайдера, без подавления проверки lint.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease --offline --no-daemon --max-workers=1 '-Dorg.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8' '-PversionCode=19' '-PversionName=1.16.3' --console=plain
```
