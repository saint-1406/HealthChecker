# Полный офлайн-каталог штрихкодов, 16.1

Пользователь явно запросил скачать всю доступную базу, встроить её без сетевого доступа и опубликовать 16.1 в GitHub. Используем полный food-снимок Open Food Facts, а не только товары с тегом Azerbaijan. GS1 не имеет подтверждённой открытой полной выгрузки. Не обещаем полного покрытия магазинов Баку. Все пригодные идентификаторы импортируются; неизвестные БЖУ не заменяются нулём.

Из официального Parquet формируется отдельная SQLite-база с индексом GTIN-14. Поля: штрихкод, название, бренд, основа/значения пищевой ценности, количество и единица упаковки. Фото всех товаров не входят: пользовательские фото v16 продолжают храниться локально. Импорт проверяет контрольную цифру и единицы, сохраняет неизвестные значения, не принимает prepared/estimate вместо этикетки, отчёт фиксирует пропуски и статистику.

Сжатая SQLite разбита на небольшие asset-части, доступные в репозитории без Git LFS. При первом обращении потоково распаковывается в приватный служебный каталог, проверяется по SHA-256 и атомарно активируется; запрос идёт через индекс, миллионы карточек не загружаются в память. Личные карточки имеют приоритет. После выбора встроенной карточки пользователь проверяет этикетку и сохраняет личную копию; резервная копия не содержит весь встроенный каталог. Ручное добавление с фото остаётся.

Встроенная база и её воспроизводимый импорт публикуются под ODbL с атрибуцией OFF/DbCL. Исходная ревизия и контрольные суммы зафиксированы. Отдельный актив готовой базы в GitHub Release делает производную базу доступной без извлечения APK.

Сканер работает только с личной/встроенной базой. Разрешение INTERNET удаляется из приложения. Встроенный WebView YouTube удаляется, ссылки открываются внешним приложением по нажатию; собственные видео и таймер сохраняются.

Версия для человека 16.1, versionCode 17, прежние applicationId и ключ. Полный релиз Latest с APK, SHA-256, базой и описанием без повторного подтверждения (AGENTS.md). Работа включает непубликованные изменения v16; данные пользователя сохраняются при обновлении.

Выбор SQLite вместо загрузки миллионов Food в JSON сохраняет быстрый запуск и ограниченную память; онлайн/API и догрузка по нажатию противоречат запросу. Выполнение прямо авторизовано пользователем («без танцев», «подготовь залей»), технические детали определяются самостоятельно.
