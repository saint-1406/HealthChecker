# Удобство ежедневного использования

Пользователь одобрил весь список улучшений 29 октября 2026 года; реализация продолжается без дополнительного согласования.

- Главные действия записи еды и воды сразу под энергией дня. Недавние продукты и избранное перед списком дневника.
- Избранные продукты (звезда в поиске) и именованные наборы еды. Набор хранит отдельные продукты с количествами и снимками нутриентов, не превращает их в рецепт. Можно создать набор из выбранных записей дня, изменить название/состав, удалить и добавить набор в редактируемую корзину.
- Для одной новой еды остаётся запись одной кнопкой. «Добавить ещё» кладёт продукт в корзину и возвращает к поиску; при непустой корзине основная кнопка записывает всё вместе. Корзину можно открыть для проверки. Редактирование существующей записи остаётся немедленным. Корзина фиксирует дату при создании, хранится на телефоне до записи/очистки, сохраняется при перезапуске; запись всей корзины — одна транзакция и одна отмена.
- Последняя порция для каждого продукта используется при следующем добавлении. Смена единиц сохраняет массу; повторное нажатие выбранной единицы ничего не сбрасывает. Если вес штуки неизвестен, пользователь вводит его явно. Вода: 200/250/500 мл, запоминается выбранный объём.
- В поиске видны метки «Сырой», «Готовый», «Сухой» по исходному английскому названию и «≈ Оценка» для local: позиций. Без подмены данных. Фильтры «Все / Избранное / Мои продукты».
- Профиль позволяет скрыть/показать карточки веса, шагов, тренировок на обзоре; по умолчанию прежний состав. Лекарства без карт — компактная кнопка добавления вместо пустого раздела.
- Видимые отдельные статусы локального сохранения и резервной копии; предложение настроить копию после первого сохранения, с возможностью отложить. Подготовка всех картинок до изменения БД, согласованный откат файлов при ошибке восстановления; восстановление после аварийного завершения по журналу и маркеру БД.
- Русский и английский интерфейс, Android 8+, офлайн. Старые копии читаются; новая схема 7 хранит избранное/наборы. Корзина и настройки конкретного телефона не включаются в переносимую копию.
- Проверка сценариев на эмуляторе, маленьком экране и шрифте 200%; доступные подписи и цели касания от 48 dp. Реальный телефон — только если подключён пользователем.
- Локальный подписанный полный APK v14. Публикация GitHub в этот запрос не включена.
