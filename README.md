# HealthChecker

Самостоятельное Android-приложение для дневника питания и домашних тренировок. Android 8.0 и новее. Интерфейс на русском или английском, офлайн-каталог на двух языках, калории, белок, жиры, углеводы, клетчатка и питьевая вода, свои блюда из ингредиентов, лекарства и витамины с картой препарата, шаги с оценкой калорий, журнал веса с трендом, 213 домашних упражнений на двух языках с анимированными схемами движений, экран тренировки с таймером отдыха и секундомером, видеотренировки (YouTube или свой файл) с разметкой упражнений и записью в дневник одной кнопкой. Без регистрации; в интернет приложение выходит только для видео с YouTube и только по вашему нажатию.

Базовая версия — полноценная последняя сборка на момент выпуска (сейчас v6). Обновление из релиза тоже полноценный установщик: его можно ставить и поверх любой прежней версии, и с нуля.

Как установить на Android 8.0 и новее:

1. Откройте ссылку на телефоне и скачайте APK.
2. Откройте скачанный файл. Если Android спросит, разрешите установку приложений из этого браузера или файлового менеджера.
3. Google Play Защита может предупредить, что приложение от неизвестного разработчика: приложение не из Google Play, нажмите «Подробнее» → «Всё равно установить».
4. Чтобы обновиться, скачайте APK из последнего релиза (номер больше установленного) и откройте его поверх приложения — дневник сохранится. Не удаляйте приложение перед обновлением.
5. Какая версия стоит, видно внизу **Профиля** («HealthChecker · версия 11») и в настройках Android → Приложения → HealthChecker (начиная с v11; у более ранних там написано «1.0»).

Аккаунт не нужен, данные остаются на телефоне. Интернет нужен только проигрывателю YouTube во «Видеотренировках» — после нажатия «Загрузить видео»; всё остальное работает офлайн.

## Установка и обновление

В папке `dist` локальной сборки (в `releases/` репозитория лежит только базовый установщик; обновления выходят как релизы GitHub):

| Файл | Что это |
| --- | --- |
| `HealthChecker-base-v3.apk`, `HealthChecker-base-v6.apk` | базовые установщики: первая выданная версия 3 (архив) и текущая база v6 |
| `HealthChecker-update-v4.apk`, `…-v5.apk`, … | обновления; номер в имени — versionCode |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |
| `HealthChecker.version` | номер последнего выданного обновления |

Перенесите APK на телефон и откройте; при запросе Android разрешите установку из используемого файлового менеджера. Для новой установки можно сразу взять последнее обновление. Чтобы обновиться, откройте файл с бóльшим номером **поверх установленного приложения**: дневник сохранится. Промежуточные обновления пропускать можно. Не удаляйте прежнюю установку ради обновления и не ставьте версию с меньшим номером поверх большей — Android это запретит.

Все файлы подписаны одним ключом, applicationId остаётся `az.healthchecker.app`.

## Первые шаги

1. Выберите язык — «Русский» или «English» (позже он меняется в **Профиль → Оформление и язык**). Укажите возраст, пол для расчётной формулы, рост, вес и активность либо нажмите «Начать без расчёта».
2. В профиле можно подставить приблизительную калорийность для поддержания веса или задать все цели вручную. Белок и воду задайте самостоятельно; пустое поле означает отсутствие цели.
3. В дневнике найдите продукт, выберите граммы, штуки или доступные для жидкости миллилитры. При выборе штук проверьте **вес одной штуки**. Добавьте каждое съеденное отдельно.
4. Обзор показывает выбранный календарный день и последние семь дней. Старые записи и цели доступны по дате. Это не скользящие последние 24 часа.
5. Утром взвешивайтесь и нажмите **«Записать»** в карточке **«Вес»** на обзоре: карточка покажет последний вес, изменение за неделю и направление — снижается, растёт или стабилен.
6. Нажмите на карточку **«Энергия за день»**: откроется окно с белками, жирами, углеводами и клетчаткой за день и теми же значениями для каждой записи отдельно. В дневнике под каждой записью тоже видно «Б · Ж · У · Кл».

Сырые и приготовленные продукты различаются. 50 г сухих хлопьев — не то же, что 50 г готовой каши. Нажмите запись для исправления; исправление не переносит запись на другой день. Удаление и быстрое добавление воды можно отменить кнопкой «Отменить» внизу экрана. «Недавние продукты» в дневнике подставляют количество из прошлой записи.

В конце дня отметьте «День заполнен», чтобы явно учитывать даже пустой день в средней статистике. Дни без записей и дни, где калорийность части продуктов неизвестна, в среднее не входят.

## Белок

Нажмите на карточку **«Белок»** на обзоре — откроется отдельный экран:
- сегодня: сколько белка съедено, сколько осталось до цели, какую долю калорий дня даёт белок и сколько граммов приходится на килограмм веса;
- график по дням за 7 или 30 дней с линией цели, среднее за дни с полными данными и число дней, когда цель выполнена; средние граммы на килограмм веса (взрослым обычно советуют от 0,8 г/кг, при силовых тренировках — 1,2–2 г/кг);
- главные источники белка за период;
- **продукты с белком** на 100 г: поиск по названию и по числу граммов белка — «не меньше», «около» (±10 %) или «не больше»; сортировка «больше → меньше», «меньше → больше» и «больше на 100 ккал». По умолчанию список — частые продукты и ваши собственные, переключатель «Весь каталог» ищет среди всех 7834. Нажатие на продукт открывает его запись в дневник, после сохранения вы возвращаетесь к экрану белка.

## Фото на потом

Нет времени записывать сразу — сфотографируйте. В **«Дневнике»** рядом с «Записать еду» есть кнопка камеры: «Сфотографировать еду», «Сфотографировать лекарство» или «Добавить из галереи». Пока снимки ждут, в дневнике видна карточка **«Фото на потом»** с ними. Фото хранится внутри приложения (в общей галерее телефона его нет), уменьшается до 2048 пикселей и ждёт; на обзоре появляется напоминание «N фото ждут внесения». Разрешение на камеру приложению не нужно: снимок делает системное приложение камеры.

Когда будет время, нажмите на фото: верхняя половина экрана — снимок (приближается двумя пальцами или двойным касанием, кнопка «⤢» увеличивает его на большую часть экрана), нижняя — обычная форма. Для еды найдите продукт или **создайте свой по этикетке**, переписывая цифры с фото, и добавьте порцию; для лекарства отметьте приём или создайте карту препарата. Всё записывается на день, когда сделано фото. После «Готово» фото можно удалить (удаление отменяется) или оставить. Распознавания текста и подсчёта по фото нет: без интернета и нейросетей это ненадёжно, цифры переписываете вы. Фото на потом не входят в резервную копию.

## Оформление

**Профиль → Оформление и язык → «Темы, цвета и фон»**:
- **режим** — как в системе, светлый или тёмный;
- **цвет интерфейса** — «Мята» (исходный вид), «Океан», «Лаванда», «Ягода», «Коралл», «Янтарь», «Лес», «Графит» или **свой цвет** ползунком оттенка. Из цвета строится вся палитра: кнопки, переключатели, графики, фон экранов и карточек; контраст текста проверяется автоматически (тест сверяет все палитры и 24 оттенка со стандартом WCAG в светлом и тёмном режиме);
- **праздничные темы** включаются сами: **Хэллоуин** с 25 октября по 7 ноября (тыквенно-оранжевый и фиолетовый, ночью — почти чёрный фон), **Новый год** с 26 декабря по 8 января (красный и хвойно-зелёный на снежном или ночном синем фоне). Выбор другого цвета во время праздника выключает его тему до следующего праздника; попробовать праздничную тему можно в любой день, а автоматическое включение — отключить;
- **украшения и анимация**: на Новый год падает снег и мигает гирлянда, на Хэллоуин — луна, летучие мыши, паутина и тыквы; они бледные и лежат за карточками, их можно выключить;
- **свой фон** — любая картинка из галереи за всеми экранами (хранится только в приложении, уменьшается до 1920 пикселей), с ползунками «Приглушить картинку» и «Плотность карточек», чтобы текст оставался читаемым;
- «Вернуть стандартное оформление».

Оформление хранится на телефоне и в резервную копию не входит.

В **дневнике** вверху — сводка дня: калории против цели кольцом, полоса распределения энергии между белками, жирами и углеводами, граммы каждого и клетчатка с водой. У каждой записи — значок (капля для воды, тарелка для своих блюд, иначе первая буква), время записи и такая же полоса БЖУ. Камера «Фото на потом» — кнопка рядом с «Записать еду».

## Блюда и инвентарь

**Профиль → Инвентарь** хранит приготовленные вами блюда — каждое в своей ячейке с иконкой. Ячейка «Новое блюдо» (или «+ Создать блюдо из ингредиентов» в поиске продуктов) открывает конструктор: название, иконка, ингредиенты с количеством в граммах или штуках (вес штуки виден и редактируется). Например, куриное филе 500 г, морковь, картофель 5 шт., зелень 1 пучок.

Приложение суммирует калории и БЖУ ингредиентов. Если указать **вес готового блюда** (взвесьте без посуды), значения на 100 г считаются по нему: при варке вода выкипает или впитывается. Без веса расчёт идёт по сырым ингредиентам. Можно указать число порций — появится порция «1/N». Если у одного ингредиента неизвестен нутриент, у блюда он тоже показывается неизвестным.

Нажмите на блюдо в инвентаре: окно покажет состав и пищевую ценность. Там же можно ввести граммы и нажать **«Съесть»** — запись попадёт в дневник за выбранный день — или **«Удалить блюдо»**. Блюдо находится и в обычном поиске продуктов. Удаление и изменение блюда не меняют уже записанную еду: каждая запись хранит свои значения.

## Тренировки

Вкладка **«Тренировки»**: отметка «Была тренировка / Не было» за выбранный день (выполненные упражнения отмечают день автоматически), список выполненного и карточка рекомендаций на сегодня с картинками упражнений и кнопкой **«Начать тренировку»**. В настройках вкладки укажите, есть ли гантели, и уровень.

**Экран «Тренировка сейчас»** открывается из этой карточки. Каждое упражнение подборки — отдельная карточка: картинка движения, русское и английское название, подходы и повторения, полное описание техники, отдых между подходами. «Записать» сохраняет упражнение ровно как предложено (отменяется в подсказке внизу), «Изменить» открывает форму упражнения. Вверху — сколько выполнено из подборки и оценка времени и калорий. Внизу экрана всегда видны **таймер отдыха** (30 с, 60 с, 90 с, 2 мин, «+15 с», пауза) и **секундомер**; у упражнений на время есть кнопка «Таймер 30 с» на длину подхода. За три секунды до конца таймер коротко пищит, в конце — длинный сигнал и вибрация (звук идёт через громкость мультимедиа, его слышно в наушниках поверх видео). Пока экран открыт, он не гаснет. Подборка строится по прошлым дням, поэтому записанные упражнения не перемешивают её.

**Видеотренировки** — кнопка «Видеотренировки» на вкладке «Тренировки», сразу под «Добавить упражнение». Самих роликов в приложении нет (это сотни мегабайт чужого видео — поэтому обновление весит около 2,5 МБ): в нём разметка упражнений, а видео играет из вашего файла или открывается в YouTube. В библиотеке две тренировки канала «재호 - Fitness» (Jaeho), по которым вы занимаетесь: «30 MIN FULL BODY WORKOUT with WARM UP» (34 упражнения: разминка 9 × 30 с, затем ноги, верх тела, пресс и кардио по 40 с работы и 20 с отдыха) и «25 MIN FULL BODY WORKOUT AT HOME» (3 круга по 8 упражнений, 40/20 с). Для каждой выписана разметка: какое упражнение идёт с какой секунды, его название на экране видео и упражнение из каталога со схемой движения. На экране видео видно, что идёт сейчас и сколько осталось («Сейчас · Squat Knee to Elbow — Присед с подъёмом колена к локтю, 0:23»), или «Отдых · далее: …»; нажатие на упражнение в списке переносит видео к нему.

- **Свой файл с телефона.** «Прикрепить свой файл» — системный выбор файла; видео играет прямо в приложении, без интернета, вместе с разметкой (пауза, перемотка, «на весь экран»). Приложение хранит только ссылку на файл, сам файл остаётся на месте. После переустановки приложения файл нужно прикрепить заново.
- **YouTube.** Видео загружается из интернета только после нажатия «Загрузить видео» — официальный проигрыватель YouTube (IFrame) внутри приложения. Автор этих двух роликов запретил показ в других приложениях (YouTube отвечает «Playback on other websites has been disabled by the video owner»), поэтому для них кнопка «В YouTube» открывает приложение YouTube сразу с нужного места, а разметка в HealthChecker идёт по таймеру: нажмите «Старт по разметке» одновременно с видео (кнопки «−10 с»/«+10 с» подгоняют). Видео других авторов, которые разрешают встраивание, играют прямо в приложении.
- **Свои видео.** «Ссылка YouTube» добавляет любое видео по ссылке (watch, youtu.be, shorts), «Файл с телефона» — видеофайл. У своих видео разметки нет: их записывают как «Кардио-тренировку по видео» (умеренную или интенсивную) по минутам.
- **Изменить видео** — карандаш в заголовке экрана видео: название, описание и ссылка YouTube. У встроенных тренировок разметка упражнений остаётся прежней, поэтому ссылку стоит менять на то же видео — например, на копию, которую разрешено встраивать: тогда приложение предложит «Загрузить видео». «Вернуть исходные» возвращает название, описание и ссылку из приложения. Изменения входят в резервную копию.
- **Скачивание.** Скачивать ролики с YouTube приложение не будет: это запрещают правила YouTube. «Загружаемые» видео здесь значит: вы сами решаете, загружать ли видео из интернета (ничего не грузится без нажатия), а для занятий без интернета прикрепляете свой файл.
- **«Записать тренировку в дневник».** Всё видео или только до текущего места: каждое упражнение разметки попадает в «Выполненные» за выбранный день, повтор одного упражнения (прыжки «звёздочка» в разминке и в кардио) становится ещё одним подходом. Время — время работы по разметке, отдых не считается; повторения оцениваются по темпу упражнения; калории — как у любой записи, по MET и весу. Запись всей 30-минутной тренировки отменяется одной кнопкой «Отменить».

**Картинки движений** нарисованы самим приложением для всех 213 упражнений: схематичная фигура, которая повторяет движение по ключевым позам (дальние рука и нога бледнее, гантели — короткие перекладины в руках). Они собственные, не взяты из чужих баз (генератор — `tools/exercises/figures.py`). Если добавить свою картинку, она заменяет схему.

Каталог — 213 упражнений для дома: 176 без инвентаря и 37 с гантелями. 11 из них добавлены по 30-минутной видеотренировке: разведение рук «Т» стоя, подъёмы рук через стороны, приседания с шагом в сторону, выпад назад с подъёмом колена, отжимание с подтягиванием колена, отжимание с разворотом «Т», сгибание и выпрямление ног лёжа (Leg Press), повороты коленей лёжа (T-Rotation), планка с поворотом таза, присед и «звёздочка», А-скип. Направления: разминка, силовые, аэробика, выносливость, интервальные (HIIT), растяжка, йога и пилатес, баланс. У каждого упражнения есть русское и английское название и описание техники; карточка показывает оба названия, а там, где упражнение известно по видеотренировкам, ещё и название из видео (например, «Приседания, руки у головы» — Prisoner squat · OH Squat).

Поиск понимает русские и английские названия, названия из видео, разговорные слова («пресс», «скакалка», «разминка»), мышцы и направление; лучшие совпадения — сверху, формы слова учитываются. Фильтры: мышцы, направление, гантели.

В карточке упражнения можно **добавить свою картинку** — скриншот из видео или фото, по которому легко вспомнить технику. Картинка выбирается через системный выбор фото (без разрешений), уменьшается до 1280 пикселей, хранится в приложении и входит в резервную копию; её можно открыть на весь экран, заменить или убрать.

**Секундомер** есть на экране тренировки и в карточке упражнения: старт, пауза, сброс. Пока он идёт, экран не гаснет, а время продолжает считаться при переходе между экранами (например, пока вы смотрите видео). В карточке упражнения кнопка «Подставить» переносит время в поле: для упражнений на время — в секунды подхода, для остальных — в общее время.

Расход энергии — оценка по таблицам 2024 Adult Compendium of Physical Activities: **ккал ≈ MET × вес тела × время**. Для подходов время оценивается по темпу и минутному отдыху и редактируется. Нужен вес: берётся последний записанный вес, иначе вес из профиля. Калории тренировок показываются отдельно и не увеличивают цель по еде.

Рекомендации собирают разминку, 4–6 упражнений на группы мышц, которые не нагружались вчера, кардио — пока не набран недельный ориентир, — и заминку. Ориентир ВОЗ для взрослых: 150 минут умеренной аэробной нагрузки в неделю (интенсивные минуты считаются вдвойне) и силовые упражнения не меньше 2 дней. «Другая подборка» меняет упражнения. Это не медицинская программа: при боли и заболеваниях посоветуйтесь с врачом.

## Вес

Карточка **«Вес»** на обзоре: последний записанный вес и дата, изменение за неделю и за месяц, изменение с начального веса профиля и график за 90 дней. Утренний вес колеблется на килограмм из-за воды и соли, поэтому направление считается по **средним за 7 дней** против средних предыдущей недели; изменения меньше 0,2 кг показываются как «стабилен». Пока данных меньше двух недель, сравниваются первый и последний вес недели. Одна запись на день: повторная в тот же день заменяет прежнюю. Нажмите на карточку — откроется история с графиком, где лишнюю запись можно удалить (с отменой). Новый вес становится текущим весом профиля (начальный не меняется) и используется для калорий тренировок и шагов.

## Лекарства и витамины

В дневнике под едой — раздел **«Лекарства и витамины»**. «Добавить препарат» открывает карту: тип (лекарство, витамин, БАД), название, форма выпуска, действующие вещества с дозировкой (например, витамин D3 2000 МЕ в капсуле), сколько принимать за раз и сколько раз в день, время приёма, до/во время/после еды или натощак, курс с датами начала и окончания, для чего, кто назначил и заметки. Пока идёт курс, препарат виден в дневнике каждого дня: кнопка **«Принял»** отмечает приём со временем, счётчик показывает «Принято: 1 из 2», лишнюю отметку можно убрать. Напоминаний нет; приложение не проверяет дозировки и взаимодействия.

## Шаги

Карточка **«Шаги»** на обзоре открывает шаги выбранного дня. Число можно ввести вручную (например, с часов) — оно заменяет подсчёт телефона за этот день. Калории считаются по росту и весу из профиля: ходьба 3,8 MET (Compendium 2024, код 17190) × вес × время при длине шага ≈ 0,415 × рост и скорости 5 км/ч. Они показываются отдельно и не меняют цель по еде.

Переключатель **«Считать шаги автоматически»** включает шагомер на встроенном датчике телефона, как в Google Fit: без интернета и почти без расхода батареи. Нужно разрешение «Физическая активность» (Android 10+); пока подсчёт включён, в шторке висит тихое уведомление — без него Android не даёт приложениям получать шаги в фоне. Шаги считаются с момента включения, подсчёт продолжается после перезагрузки. На телефонах без датчика шагов остаётся ручной ввод.

## Сохранение после удаления приложения

Android удаляет внутреннюю базу при удалении приложения. Для восстановления заранее откройте **Профиль → Резервная копия → Выбрать папку** и выберите отдельную папку во внутренней памяти, например `Documents/HealthChecker`. Убедитесь, что показано время успешной копии и нет сообщения о несохранённых изменениях.

После подключения папки приложение сохраняет копию при изменениях, пока оно работает. Файл сначала записывается отдельно и проверяется чтением; предыдущая исправная копия сохраняется. Если доступ отозван, место закончилось или приложение закрыто до завершения записи, последняя успешная копия остаётся, а новые изменения могут ещё не быть в ней. Статус и текст ошибки видны в профиле, а на обзоре появляется предупреждение «Резервная копия не обновляется»; есть кнопка ручного повторения. Если доступ к папке пропал, выберите ту же папку снова — копия запишется сразу. В папке хранятся две последние проверенные копии.

После переустановки выберите **«У меня уже есть резервная копия»** на стартовом экране либо **Профиль → Восстановить из файла**. Укажите последний исправный `HealthChecker-….json`, проверьте число записей и подтвердите замену текущего дневника. Затем **заново выберите папку** для следующих копий: разрешения Android после удаления теряются.

Копии содержат личный профиль, дневник, блюда, тренировки, картинки упражнений, вес, лекарства с отметками приёма, шаги и добавленные вами видео и ваши изменения встроенных (названия, описания, ссылки YouTube) в читаемом JSON (картинки — внутри файла в виде JPEG). Прикреплённые видеофайлы в копию не входят: это ссылки на файлы этого телефона. Копии прежних версий (форматы 1–5) восстанавливаются и в новой версии; копию формата 6 (v11: видео и их изменения) версии 10 и старше не прочитают. Храните их в выбранном вами безопасном месте. Облачная синхронизация и Android Auto Backup не используются. Без сохранённой внешней копии восстановление после удаления невозможно. Настройка темы и разрешение папки в копию не входят.

## Каталог и точность

7 834 позиции: 7 793 из USDA SR Legacy и 41 добавленная. У каждой позиции и каждой порции есть русское и английское название: английское — оригинал USDA, русское — его перевод (значения не менялись). Поиск понимает оба языка, азербайджанские слова (в том числе без ə, ş, ç) и разные формы слова («грудки», «варёная»); повседневные продукты — варёная куриная грудка, эспрессо, эспрессо двойной, чай, кола, творог, сметана и другие — показываются первыми. Клетчатка (USDA «Fiber, total dietary») указана для 7 398 позиций; у записей, сделанных до её появления, она подставляется из каталога.

Ресторанные блюда Баку — вырезка с гранатом (с каштанами и без), отварные хинкали, куриный попкорн, жареная дюшбара, креветки в темпуре, сосиски, фисташки Антеп — это расчётные оценки по присланным данным: калории, белки и жиры взяты как даны, углеводы и клетчатка рассчитаны по ингредиентам USDA или как остаток энергии; как получено каждое значение, написано в карточке продукта. Для отсутствующего точного бренда создайте свой продукт по этикетке. Это не полный каталог магазинов Азербайджана.

Суши, как в суши-барах Баку, — 32 позиции: роллы Филадельфия, Калифорния, Аляска, Канада, Дракон, Зелёный дракон, Бонито, Кани, Чука, Чипсы, пряный сырный, запечённые с лососем и крабом, горячие (темпура) с креветкой, лососем и курицей; маки с лососем, креветкой, огурцом, авокадо, тунцом и угрём; нигири, гункан, сашими, салат чука и мисо-суп. Их удобно записывать **штуками**: вес кусочка уже подставлен, есть порция «Ролл 8 шт.» (у маки — 6 шт.). Для 12 роллов из присланного набора калории, белки и углеводы — середина присланных диапазонов на кусочек, жиры — остаток энергии; остальные позиции рассчитаны по типичному составу кусочка из ингредиентов USDA (рис с сахаром, нори, рыба, сыр, соусы, кляр и масло фритюра). Соевый соус, имбирь, васаби и эдамаме находятся первыми. Рестораны различаются — вес кусочка можно поправить.

Open Food Facts при подготовке отвечал HTTP 503, поэтому его данные не включены. Подробности, ограничения региональных аналогов и воспроизведение импорта: [источники](docs/catalog-sources.md).

Значения продуктов средние, порции в штуках приблизительные. Неизвестные нутриенты отмечаются прочерком, частичные суммы — специальной отметкой. Цель воды относится только к выпитой питьевой воде. Калорийность по Mifflin–St Jeor — ориентир для взрослых на поддержание веса; для возраста до 18 лет автоматическая оценка не применяется.

## Сборка из исходников

Требуются JDK 17, Android SDK 36 и Build Tools 36.0.0. SDK указывается в локальном `local.properties` строкой вида `sdk.dir=C\:/путь/к/sdk` (двоеточие экранируется, иначе lint остановит сборку). В этой рабочей копии SDK, эмулятор и образ API 36 лежат в `.local/android-sdk`, тестовый AVD — в `.local/avds`. Gradle wrapper включён.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
python -m unittest discover -s tools/catalog
python -m unittest discover -s tools/exercises
python tools/exercises/videos.py
.\gradlew.bat :app:connectedDebugAndroidTest
.\scripts\build-apk.ps1 -VersionCode 11
```

Последняя команда проверяет unit-тесты, lint, подпись, applicationId и versionCode release-сборки, затем кладёт новый файл `dist/HealthChecker-update-v<номер>.apk` рядом с прежними (базовая версия и старые обновления не трогаются), дописывает его SHA-256 в `dist/SHA256SUMS.txt` и номер в `dist/HealthChecker.version`. Рядом пишется `dist/HealthChecker-update-v<номер>.apk.sha256`. С ключом `-Publish` (после `git push` в `main`) скрипт создаёт релиз GitHub `v<номер>` с этим APK и его контрольной суммой; нужен GitHub CLI, один раз войти командой `gh auth login`. Базовый установщик в `releases/` меняется только отдельным решением. Номер должен быть больше выданного (сейчас выдан **10**, следующий — 11), иначе Android не поставит обновление поверх; скрипт это проверяет. При ошибке предыдущий APK в `dist` не заменяется.

Локальный постоянный ключ текущей установки находится в `.local/signing/healthchecker.jks`; пароль — в `.local/signing/password.txt`, конфигурация сборки — в `signing.properties`. Эти файлы исключены из Git. **Сохраните ключ и пароль отдельно:** без прежнего ключа обновить уже установленный APK нельзя. Не публикуйте их вместе с исходниками.

Для собственной новой подписи создайте keystore и локальный `signing.properties` с полями `storeFile` (абсолютный путь), `storePassword`, `keyAlias`, `keyPassword`. Смена подписи потребует удаления старой установки; сначала сохраните дневник.

Проверки и ограничения текущей сборки фиксируются в [docs/testing.md](docs/testing.md).
