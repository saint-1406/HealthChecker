# Правила проекта

## Публикация обновлений

Когда пользователь говорит «залить / закоммитить / отправить в гит» или аналогичную фразу, он имеет в виду полный выпуск: отправить код в GitHub и опубликовать новый релиз с полным подписанным APK, файлом SHA-256 и описанием изменений, отметив релиз как Latest. Отдельное повторное подтверждение публикации не требуется. Явные ограничения пользователя в конкретном запросе имеют приоритет.

Перед публикацией проверить состояние удалённой ветки, соответствие APK выпускаемому коду, номер версии, прежние applicationId/ключ подписи и контрольную сумму загруженного установщика. Не переписывать историю и не заменять уже опубликованный APK другим содержимым под тем же номером. Секреты подписи и учётные данные в Git не добавлять.
